# Список тестов для лексического анализатора Astra

## Базовые тесты
- [x] Пустой входной поток
- [x] Только пробельные символы
- [ ] Только комментарии

## Комментарии
- [ ] Однострочный комментарий `# комментарий`
- [ ] Многострочный комментарий `/* комментарий */`
- [ ] Вложенные многострочные комментарии
- [ ] Комментарий в середине кода
- [ ] Незакрытый многострочный комментарий (ошибка)

## Ключевые слова
- [ ] Все ключевые слова: `start`, `end`, `namespace`, `import`, `let`, `const`, `func`, `return`, `if`, `else`, `for`, `in`, `while`, `break`, `continue`, `show`, `true`, `false`, `null`, `type`
- [ ] Ключевые слова в разных регистрах (должны не совпадать)
- [ ] Ключевые слова как часть идентификаторов

## Идентификаторы
- [ ] Простые идентификаторы: `index`, `_buffer`, `Matrix2D`
- [ ] Идентификаторы с цифрами: `user1`, `temp2Value`
- [ ] Невалидные идентификаторы (начинающиеся с цифры)
- [ ] Идентификаторы с подчеркиванием: `__private__`

## Числовые литералы
- [ ] Целые числа: `42`, `-15`, `0`
- [ ] Вещественные числа: `3.14`, `-2.5`
- [ ] Научная нотация: `1e6`, `-2.3e-4`
- [ ] Шестнадцатеричные: `0xFF`, `0x1A3`
- [ ] Невалидные числа: `123.`, `.456`

## Строковые литералы
- [ ] Двойные кавычки: `"Hello"`
- [ ] Одинарные кавычки: `'World'`
- [ ] Многострочные строки: `"""Line1\nLine2"""`
- [ ] Экранированные последовательности: `\n`, `\t`, `\"`, `\\`
- [ ] Незакрытая строка (ошибка)

## Булевы литералы и null
- [ ] `true`
- [ ] `false` 
- [ ] `null`

## Операторы
- [ ] Арифметические: `+`, `-`, `*`, `/`, `%`, `**`
- [ ] Сравнения: `==`, `!=`, `<`, `<=`, `>`, `>=`
- [ ] Логические: `and`, `or`, `not`
- [ ] Присваивания: `=`, `+=`, `-=`, `*=`, `/=`, `%=`
- [ ] Тернарный: `if`, `else` (в контексте оператора)
- [ ] Тип возврата: `->`

## Разделители и специальные символы
- [ ] Запятая: `,`
- [ ] Двоеточие: `:`
- [ ] Точка с запятой: `;`
- [ ] Скобки: `()`, `[]`, `{}`

## Комплексные сценарии
- [ ] Простая программа из примера спецификации
- [ ] Выражения с операторами разного приоритета
- [ ] Вложенные структуры и вызовы функций
- [ ] Смешанные типы лексем в одной строке
- [ ] Позиция и длина каждой лексемы

## Обработка ошибок
- [ ] Неизвестные символы
- [ ] Неожиданный конец файла
- [ ] Некорректные escape-последовательности
- [ ] Несоответствующие типы чисел
