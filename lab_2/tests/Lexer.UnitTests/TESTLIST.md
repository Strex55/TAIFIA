# Список тестов для лексического анализатора Astra

## Базовые тесты
- [x] Пустой входной поток
- [x] Только пробельные символы
- [x] Только комментарии

## Комментарии
- [x] Однострочный комментарий `# комментарий`
- [x] Многострочный комментарий `/* комментарий */`
- [x] Комментарий в середине кода

## Ключевые слова
- [x] Все ключевые слова: `start`, `end`, `namespace`, `import`, `let`, `const`, `func`, `return`, `if`, `else`, `for`, `in`, `while`, `break`, `continue`, `show`, `true`, `false`, `null`, `type`, `and`, `or`, `not`
- [x] Ключевые слова в разных регистрах (должны не совпадать)
- [x] Ключевые слова как часть идентификаторов

## Идентификаторы
- [x] Простые идентификаторы: `index`
- [x] Идентификаторы с подчеркиванием: `_buffer`
- [x] Идентификаторы с цифрами: `Matrix2D`, `user1`, `temp2Value`
- [x] Идентификаторы с подчеркиванием в начале: `__private__`

## Числовые литералы
- [x] Целые числа: `42`, `0`, `-15`
- [x] Вещественные числа: `3.14`, `-2.5`
- [x] Научная нотация: `1e6`
- [x] Шестнадцатеричные: `0xFF`, `0x1A3`

## Строковые литералы
- [x] Двойные кавычки: `"Hello"`
- [x] Одинарные кавычки: `'World'`
- [x] Многострочные строки: `"""Многострочный\ntекст"""`
- [x] Экранированные последовательности: `\n`, `\t`, `\"`, `\\`

## Булевы литералы и null
- [x] `true`
- [x] `false`
- [x] `null`

## Операторы
- [x] Арифметические: `+`, `-`, `*`, `/`, `%`, `**`
- [x] Сравнения: `==`, `!=`, `<`, `<=`, `>`, `>=`
- [x] Логические: `and`, `or`, `not`
- [x] Присваивания: `=`, `+=`, `-=`, `*=`, `/=`, `%=`
- [x] Тип возврата: `->`

## Разделители и специальные символы
- [x] Запятая: `,`

- [x] Точка с запятой: `;`
