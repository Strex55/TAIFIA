# Сравнение лексической структуры Python и C#

## 1. Общие характеристики

| Аспект | **Python** | **C#** |
|--------|-------------|--------|
| Тип языка | Интерпретируемый, динамически типизированный | Компилируемый, статически типизированный |
| Тип грамматики | Контекстно-зависимая (отступы значимы) | Контекстно-свободная (фиксированные токены) |
| Комментарии | `#` до конца строки | `//`, `/*...*/` |
| Конец инструкции | Перевод строки (`NEWLINE`) | `;` |
| Разделение блоков | Отступы (`INDENT/DEDENT`) | Фигурные скобки `{}` |

**Пример:**

```python
# Python
if True:
    print("OK")
```
```C#
// C#
if (true) {
    Console.WriteLine("OK");
}

```

**Вывод:**  
Python требует контекстного анализа отступов; C# использует формальный набор разделителей.

---

## 2. Элементы структурного программирования

| Элемент | **Python** | **C#** |
|----------|-------------|--------|
| Блок кода | Определяется уровнем отступа | Определяется фигурными скобками `{}` |
| Ветвления | `if`, `elif`, `else` | `if`, `else if`, `else`, `switch` |
| Циклы | `for`, `while`, `break`, `continue` | `for`, `while`, `do...while`, `foreach`, `break`, `continue` |

**Пример:**

```python
# Python
for i in range(3):
    if i % 2 == 0:
        print("Even")
```
```C#
// C#
for (int i = 0; i < 3; i++) {
    if (i % 2 == 0)
        Console.WriteLine("Even");
}
```

**Лексические особенности:**  
- Python требует токенов `:` и `INDENT/DEDENT` для начала и конца блока.  
- В C# роль отступов незначима — только `{}` определяют границы блока.

## 3. Средства ввода/вывода и встроенные функции

| Аспект | **Python** | **C#** |
|--------|-------------|--------|
| Ввод | `input()` | `Console.ReadLine()` |
| Вывод | `print()` | `Console.WriteLine()` |
| Пространства имён | Нет, встроенные идентификаторы | Требуется `System.` или `using System;` |

**Лексика:**  
- В Python встроенные функции — обычные идентификаторы (`NAME`).  
- В C# идентификаторы состоят из `namespace.identifier`, лексер должен учитывать `.` как часть выражения.

**Пример:**

```python
# Python
name = input("Enter: ")
print(name)
```
```C#
// C#
string name = Console.ReadLine();
Console.WriteLine(name);
```
---

## 4. Пользовательские функции

| Аспект | **Python** | **C#** |
|--------|-------------|--------|
| Определение | `def name(params):` | `static type Name(type param)` |
| Возврат | `return` | `return;` |
| Аргументы | Не типизированы (`*args`, `**kwargs`) | Строго типизированы |
| Тело функции | Отступы | `{}` |

**Лексические отличия:**  
- Python использует `def`, `:` и `INDENT` как сигналы начала блока.  
- C# использует скобки и ключевые слова типов (`int`, `void` и др.).

**Пример:**

```python
# Python
def add(a, b):
    return a + b
```
```C#
// C#
static int Add(int a, int b) {
    return a + b;
}
```
---

## 5. Встроенные типы данных

| Тип | **Python** | **C#** |
|------|-------------|--------|
| Целые | `int` (безразмерный) | `int`, `long`, `short`, `byte` |
| С плавающей точкой | `float` | `float`, `double`, `decimal` |
| Строки | `str` (`'...'`, `"..."`, `f"..."`, `r"..."`) | `string` (`"..."`, `$"..."`, `@"..."`) |

**Лексические различия:**  
- В Python допускаются префиксы `f`, `r`, `b`; C# — `$` и `@`.  
- Литералы чисел в Python могут содержать `_`, а в C# — суффиксы (`f`, `d`, `m`).

**Пример:**

```python
# Python
x = 3.14
text = f"Pi = {x}"
```
```C#
// C#
double x = 3.14;
string text = $"Pi = {x}";
```

## 6. Выражения и операторы

| Категория | **Python** | **C#** |
|------------|-------------|--------|
| Арифметика | `+ - * / // % **` | `+ - * / % ++ --` |
| Логика | `and or not` | `&& || !` |
| Сравнение | `== != < > <= >=` | `== != < > <= >=` |
| Присваивание | `= += -= *= /= //=` | `= += -= *= /= %= &= |= ^= <<= >>=` |
| Тернарный | `x if cond else y` | `cond ? x : y` |

**Лексика:**  
- Python использует **ключевые слова** для логики, C# — **символы**.  
- В Python часть операторов — многосимвольные (`//`, `**`), в C# — фиксированные токены.

**Пример:**

```python
# Python
max_val = a if a > b else b
```
```C#
// C#
int maxVal = (a > b) ? a : b;
```
---

## 7. Пользовательские составные типы данных

| Тип | **Python** | **C#** |
|------|-------------|--------|
| Массив / список | `list`, `tuple`, `array` | `T[]`, `List<T>` |
| Структуры | `class` (всё ссылочное) | `class`, `struct` |
| Доступ к полям | `obj.attr` | `obj.Field` |

**Лексика:**  
- Python не имеет модификаторов доступа (`public`, `private`).  
- В C# присутствуют служебные слова (`public`, `private`, `protected`), расширяющие словарь лексера.

**Пример:**

```python
# Python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
```
```C#
// C#
public struct Point {
    public int X;
    public int Y;
    public Point(int x, int y) {
        X = x; Y = y;
    }
}
```

## 8. Сводная таблица

| Критерий | **Python** | **C#** |
|-----------|-------------|--------|
| Отступы как часть синтаксиса | Да | Нет |
| Конец инструкции | Перевод строки | `;` |
| Комментарии | `#` | `//`, `/*...*/` |
| Ключевые слова | Меньше, soft-keywords | Больше, строго фиксированы |
| Строковые литералы | Префиксы `f`, `r`, `b` | Префиксы `$`, `@` |
| Типизация | Динамическая | Статическая |
| Блоки и циклы | Отступы и `:` | `{}` |
| Встроенные функции | Простые идентификаторы | Через `System.` |
| Лексическая формальность | Контекстно-зависимая | Контекстно-свободная |

---

## Итог

- **Python** — лексически гибкий, но контекстно-зависимый язык: отступы, soft-keywords, f-строки и отсутствие явных разделителей усложняют работу лексера.  
- **C#** — строго формализованный язык с фиксированными токенами и однозначной структурой, проще для автоматического анализа и компиляции.
