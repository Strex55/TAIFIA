# Лексическая структура языка Python

Этот документ описывает лексическую структуру языка Python.

## 1. Примеры кода

```Python
def calculate_sum(n: int) -> int:
    total = 0
    for i in range(1, n + 1):
        if i % 2 == 0:
            total += i
    return total

result = calculate_sum(10)
print(f"Sum: {result}")
```

## 3. Идентификаторы

Идентификатор используется для имен переменных, функций и классов.

Правила:
- Начинается с буквы Unicode (A–Z, a–z) или нижнего подчёркивания _.
- Может содержать буквы, цифры (0–9) и символ _.
- Регистр символов значим: Name и name — разные идентификаторы.
- Unicode-идентификаторы разрешены, при этом выполняется нормализация NFKC.


## 4. Операторы
Список поддерживаемых операторов:

- Арифметические: ` +, -, *, /, //, %, ** `
- Сравнения: ` ==, !=, <, >, <=, >=, is, in `
- Логические: ` and, or, not `
- Присваивания: ` =, +=, -=, *=, /=, //=, %=, **= `
- Битовые: ` &, |, ^, ~, <<, >> `

### 5.1. Литералы чисел

Допускаются следующие литералы чисел:

- Целые: `1234, 0b1010 (бинарные), 0o177 (восьмеричные), 0x9FF (шестнадцатеричные)`
- Вещественные: `3.14, 10., .001, 1e100, 3.14e-10`
- Комплексные: `3.14j, 10j`

### 5.2. Литералы строк

Строки обрамляются:

- Одинарными кавычками `'`: `'text'`
- Двойными кавычками `"`: `"text"`
- Тройными кавычками: `'''`: `'''multiline text''', """multiline text"""`

Специальные формы:

- f-строки: ` f"value: {x}" `
- r-строки: ` r"raw \n string"`
- Escape-последовательности: `\n, \t, \\, \', \", \xHH, \uXXXX`

## 6. Другие лексемы
Список прочих лексем:

- Запятая `,` — разделитель в списках, кортежах, параметрах
- Двоеточие `:` — начало блоков
- Точка `.` — доступ к атрибутам
- Скобки `()`, `[]`, `{}` — группировка, вызовы, коллекции
- Стрелка `->` — аннотация возвращаемого значения

## 7. Пробельные символы
- Пробелы, табуляции и переводы строк разделяют лексемы.
- В начале строки пробелы и табуляции значимы: они формируют токены `INDENT` и `DEDENT`.
- Отступы определяют структуру блока кода.


## 8. Комментарии
- Однострочные комментарии: `# комментарий до конца строки`
- Многострочные комментарии через тройные кавычки (формально — строковые литералы) `""" ... """`.

## 9. Специальные токены
- `EndOfFile` — конец ввода
- `Indent` — увеличение уровня отступа
- `Dedent` — уменьшение уровня отступа
- `Newline` — конец строки
- `Error` — недопустимая лексема
