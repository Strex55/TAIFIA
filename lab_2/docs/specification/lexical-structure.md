# Лексическая структура языка Astra

## 1. Общие характеристики

| Аспект | **Astra** |
|--------|-------------|
| Тип языка | Компилируемый, статически типизированный |
| Тип грамматики | Контекстно-свободная |
| Комментарии | `#`, `/* ... */` |
| Конец инструкции |Перевод строки или `;`|
| Разделение блоков | Ключевые слова start и end (как в Pascal) |
| Стиль типизации | Обязательная аннотация типов (`let x: number = 5`) |
| Чувствительность к регистру| Да |
| Пространства имён | Поддерживаются через `namespace` |

## 2. Примеры кода

```astra
namespace math

func add(a: number, b: number) -> number
    return a + b
end

start
    let result: number = add(5, 7)
    show("Result:", result)
end
```

## 3. Ключевые слова

| Слово | Назначение |
|------ |-------------|
| `start` / `end` | Границы программы или блока|
|`namespace`|Объявление пространства имён |
|`import`|Импорт модуля|
|`let` / const|Объявление переменной или константы|
|`func`|Объявление функции|
|`return`|Возврат значения|
|`if` / `else`|Условные конструкции|
|`for` / `in`|Цикл по диапазону или коллекции|
|`while`|	Цикл с условием|
|`break` / continue|Управление циклом|
|`show`|Встроенная стандартная функция вывода значений|
|`true` / `false`|Булевы литералы|
|`null`|Отсутствие значения|
|`type`|Определение пользовательского типа|

## 4. Идентификаторы

Идентификаторы используются для имён переменных, функций, пространств имён и типов.

Правила:

- Начинаются с буквы или `_`.
- Могут содержать буквы, цифры и `_`.
- Регистр имеет значение (`User` и `user` — разные идентификаторы).
- Ключевые слова не разрешены как идентификаторы.

```astra
index, _buffer, Matrix2D, userName
```

## 5. Встроенные типы данных

|Категория|Тип|Пример|Описание|
|---------|---|------|--------|
|Числовые|number|42, 3.14|Объединяет целые и вещественные|
|Логические|bool|true, false|Булевы значения|
|Строковые|text|"Hello"|Последовательность Unicode-символов|
|Коллекции|list<T>|	[1, 2, 3]|Упорядоченный список|
|Ассоциативные|	map<K,V>|{ "x": 1, "y": 2 }|Словарь (ключ-значение)|
|Специальные|null|null|Отсутствие значения|

Пример:
```astra
let name: text = "Astra"
let values: list<number> = [1, 2, 3]
let isActive: bool = true
```

## 6. Пользовательские составные типы

Astra поддерживает структуры и классы, как в C#, но без сложной иерархии наследования.

```astra
type Point
    x: number
    y: number
end
```

Типы всегда статически проверяются и имеют фиксированную структуру.
Модификаторы доступа (public, private) не используются — все поля видимы в пределах модуля.

## 7. Литералы

Литералы представляют собой непосредственные значения, используемые в исходном коде программы.
Язык Astra поддерживает числовые, строковые, булевы и специальные литералы.

### 7.1. Числовые

Числовые литералы в языке Astra имеют тип `number` и могут быть представлены в следующих формах:
* Целые десятичные числа
* Вещественные числа с десятичной точкой
* Вещественные числа в экспоненциальной форме
  
Экспоненциальная форма записи используется для представления очень больших или очень малых чисел и основана на десятичной системе счисления.

```astra
42
-15
3.14
0.001
1e6
2.5e-3
```
### 7.2. Строковые
Строковые литералы представляют собой последовательности Unicode-символов.

Поддерживаются следующие формы строк:
* Обычные строки в двойных кавычках
* Обычные строки в одинарных кавычках
* Многострочные строки в тройных двойных кавычках

```astra
"Hello"
'World'
"""Многострочный
текст"""
```
Экранирование:

`\n` - Перевод строки

`\t` - Табуляция

`\"` - Двойная кавычка

`\'` - Одинарная кавычка

`\\` - Обратный слэш

### 7.3. Булевы и специальные

Язык Astra поддерживает булевы и специальные литералы.

Булевы литералы
```astra
true
false
```
Специальный литерал
```astra
null
```
Литерал `null` обозначает отсутствие значения и может быть использован для инициализации переменных ссылочных типов или как результат функции.

## 8. Операторы
|Категория|Операторы|
|---------|---------|
|Арифметические|`+`, `-`, `*`, `/`, `%`, `**`|
|Cравнения|	`==`, `!=`, `<`, `<=`, `>`, `>=`|
|Логические|`and`, `or`, `not`|
|Присваивания|`=`, `+=`, `-=`, `*=`, `/=`, `%=`|
|Тернарный|	`a if cond else b`|
|Прочие|`->` — тип возвращаемого значения|

## 9. Функции

Функции в Astra всегда типизированы и определяются ключевым словом func.
```astra
func multiply(a: number, b: number) -> number
    return a * b
end
```

Особенности:

- Аргументы и возвращаемое значение должны иметь тип.
- Функции могут быть определены внутри `namespace`.
- Блок ограничивается `func` ... `end`.

## 10. Пространства имён и импорт

Astra поддерживает простую модульную систему:
```astra
namespace geometry

func area(w: number, h: number) -> number
    return w * h
end
```
Импорт модулей:
```astra
import geometry
show(geometry.area(3, 4))
```

## 11. Комментарии

- Однострочные:  
`# это комментарий`

- Многострочные:   
`/* длинный`  
                `комментарий */`

## 12. Пробелы и форматирование

- Пробелы и табуляции используются для разделения токенов.
- Отступы не значимы (в отличие от Python).
- Блоки всегда ограничиваются start и end.

## 13. Прочие лексемы
|Лексема|Назначение|
|-------|----------|
|`,`|	Разделитель элементов|
|`:`|	Разделитель между типом и значением|
|`;`|Конец выражения (опционален в конце строки)|
|`()`|Группировка выражений и вызов функций|
|`[]`|Индексация коллекций|
|`{}`|Блоки кода или литералы объектов|
|`->`|Аннотация возвращаемого типа функции|
