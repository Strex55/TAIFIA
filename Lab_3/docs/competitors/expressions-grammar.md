# Сравнение синтаксиса выражений в C# и Python: числовые типы и операции

## 1. Сравнение числовых типов данных

### Основные категории типов

|Тип|Python|C#|Критические различия|
|---|------|--|--------------------|
|Целые числа|	`int` (неограниченная точность)|	`sbyte`, `byte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong`|	Python автоматически переходит на длинную арифметику|
|Вещественные|	`float` (двойная точность IEEE 754)	|`float` (одинарная), `double` (двойная), `decimal` (128-битный для финансов)|	Python `float` ≈ C# `double`|
|Комплексные|	`complex` (встроенный)|	`System.Numerics.Complex` (библиотечный)|	В Python: `3+4j`|
|Логический|	`bool` (наследник int)|	`bool` (отдельный тип)|	В Python: `True == 1`, `False == 0`|
|Символьный |Нет отдельного типа(строка длины 1) |`char`(16-бит Unicode)|

## 2. Сравнение арифметических операторов


|Операция|Python|C#|Семантические различия|
|--------|------|--|----------------------|
|Сложение|	`+`|	`+`|	Python: также для конкатенации строк/списков|
|Вычитание|	`-`|	`-`|	
|Умножение|	`*`|	`*`|	Python: также для повторения строк/списков (`"a"*3`) |
|Деление|	`/` (всегда вещественное)|	`/` (зависит от операндов)|	Ключевое различие: Python `/` → `float`, C# для целых → целочисленное|
|Целочисленное деление|	`//`|	`/` (если оба целые)|		Python имеет явный оператор|
|Остаток от деления|	`%`|	`%`|	Разное поведение с отрицательными числами|
|Возведение в степень|	`**`|	`Math.Pow()`|	C# не имеет оператора степени|
|Инкремент/декремент|	Нет	|`++`, `--`	| В Python: `x += 1`|
|Побитовые|	`&`, `\|`, `^`, `~`, `<<`, `>>`|	`&`, `\|`, `^`, `~`, `<<`, `>>`	|

### Python:
```python
5 / 2      # = 2.5 (float, даже для целых)
5 // 2     # = 2 (целочисленное деление)
-5 // 2    # = -3 (округляет вниз к -∞)
-5 % 2     # = 1 (знак совпадает с делителем)
2 ** 10    # = 1024 (оператор степени)
```
### C#:
```c#
5 / 2      // = 2 (целочисленное, если оба int)
5 / 2.0    // = 2.5 (если хотя бы один double)
5 % 2      // = 1
-5 % 2     // = -1 (знак совпадает с делимым)
Math.Pow(2, 10) // = 1024 (только через метод)
int x = 5;
x++;       // = 6 (постфиксный инкремент)
```

## 3. Сравнение приоритетов операций

### Таблиц приоритетов (от высокого к низкому)

|Приоритет|Python|C#|Пример и комментарии|
|---------|------|--|--------------------|
|1  |`()` (скобки),` []`, `.`|	`()`` .`` []` `?.` `++` `--` (постф.)	|Группировка, доступ к членам|
|2  |`**`	|`+` `-` `!` `~` `++` `--` (преф.) (type)	|Python: степень; C#: унарные и приведение типа|
|3  |`+x` `-x` `~x`|	`*` `/`` %`	|Python: унарные; C#: мультипликативные|
|4	|`*` `/` `//` `%`|	`+` `-`	|Мультипликативные/аддитивные|
|5	|`+ -`|	`<<` `>>`	|Python: аддитивные; C#: сдвиги|
|6	|`<<`` >>`|	`<`` >` `<=` `>=` `is` `as`	|
|7	|`&`	|`==` `!=`	|
|8	|`^`|	`&`	|
|9	|`\|`|	`^`	|
|10	|Сравнения: `<` `<=` `>` `>=` `!=`` ==` `is` `is not`` in` `not in`	|`\|`	|Python: цепочки сравнений `1 < x <= 10`|
|11	|`not`|`	&&`|	Python: ключевое слово; C#: `&&`
|12	|`and`|	`\|\|`|	Python: ключевое слово; C#: `\|\|` |
|13	|`or`|	`??` (null-coalescing)	|
|14	|`if else` (тернарный)|	`?:` (тернарный)|	Python: особый синтаксис|
|15	|`lambda`	|`=` `+=` `-=` `*=` `/=` etc.|

### Ключевые различия в приоритетах
1. Возведение в степень (`**`) в Python имеет высший приоритет среди арифметических операторов (уровень 2), в C# нет оператора степени.

2. Унарные плюс/минус в Python имеют приоритет 3 (как у бинарных), в C# — приоритет 2 (выше мультипликативных).

3. Цепочки сравнений в Python: `1 < x <= 10` парсится как `(1 < x) and (x <= 10)`, но вычисляется более эффективно (x вычисляется один раз).

4. Логические операторы: Python использует ключевые слова (`and`, `or`, `not`), C# — символы (`&&`, `||`, `!`).

## 4. Список лево- и правоассоциативных операторов

### Левоассоциативные (вычисляются слева направо)
* Оба языка:
* Бинарные арифметические: `+` `-` `*` `/` `%` `//` (Python)
* Побитовые: `&` `|` `^` `<<` `>>`
* Сравнения (кроме цепочек в Python)
* Логические: `and`/`&&`, `or`/`||`
  
### Правоассоциативные (вычисляются справа налево)
|Python|C#|Пояснение|
|------|--|---------|
|`**` (степень)|	`=` `+=` `-=` `*=` `/=` `%=` etc.|	Присваивание|
|Унарные: `+x` `-x` `~x` `not x`|	Унарные: `+x` `-x` `!x` `~x` `++x`` --x` `(type)x`|	
|Присваивание: `=` `+=` `-=` etc.|Тернарный: `a ? b : c`	|
||`??` (null-coalescing)|

### Особая семантика Python:

```python
# Цепочки сравнений - не совсем левоассоциативны
1 < 2 < 3  # Эквивалентно (1 < 2) and (2 < 3), но '2' вычисляется один раз

# Правоассоциативное возведение в степень
2 ** 3 ** 2  # = 2 ** (3 ** 2) = 2 ** 9 = 512, а не (2 ** 3) ** 2 = 64
```

## 6. Прочие особенности синтаксиса выражений

### Неявные преобразования типов

Python: Динамическая типизация с автоматическим приведением в арифметических операциях

```Python
3 + 5.2          # 8.2 (int → float)
True + 5         # 6 (bool → int: True=1, False=0)
3 + (4 + 5j)     # (7+5j) (int → complex)
```
C#: Статическая типизация с ограниченными неявными преобразованиями ("восходящими" по иерархии)

```c#
int a = 3;
double b = 5.2;
var result = a + b;     // OK: int → double (неявное)

float f = 3.14f;
double d = f;           // OK: float → double

// bool flag = true;
// var sum = flag + a;  // Ошибка: нет неявного преобразования bool → int
```

### Переполнение и арифметика больших чисел

Python: Автоматическое расширение целых чисел, неограниченная точность

```Python
2 ** 1000                    # Работает, результат имеет ~300 цифр
10 ** 100 + 5 ** 200         # Корректная работа с большими числами
```

C#: Контроль переполнения, отдельный тип для больших целых

```c#
// Обычные целые типы (переполнение по умолчанию без исключения)
int max = int.MaxValue;
int overflow = max + 1;           // -2147483648 (без исключения)

// Контролируемое переполнение
checked {
    int max = int.MaxValue;
    // int overflow = max + 1;    // Исключение OverflowException
}

// BigInteger для произвольной точности (System.Numerics)
using System.Numerics;
BigInteger big = BigInteger.Pow(2, 1000);  // Работает аналогично Python int
```

### Специальные значения с плавающей точкой
Оба языка (наследуют от IEEE 754):

Python
```python
float('inf')    # Положительная бесконечность
float('-inf')   # Отрицательная бесконечность
float('nan')    # Не число (NaN)
math.isinf(x)   # Проверка на бесконечность
math.isnan(x)   # Проверка на NaN
```
C#
```c#
double.PositiveInfinity
double.NegativeInfinity
double.NaN
double.IsInfinity(x)
double.IsNaN(x)
```

### Работа с NaN и бесконечностями
Python
```python
# Python: NaN != NaN
x = float('nan')
x == x           # False
math.isnan(x)    # True

# Операции с бесконечностями
float('inf') > 1e308      # True
float('inf') + 1000       # inf
float('inf') * 0          # nan
```
C#
```c#
// C#: NaN != NaN
double x = double.NaN;
x == x                    // False
double.IsNaN(x)           // True

// Операции с бесконечностями
double.PositiveInfinity > double.MaxValue  // True
double.PositiveInfinity + 1000             // PositiveInfinity
double.PositiveInfinity * 0                // NaN
```
